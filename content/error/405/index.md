# 405 Method Not Allowed

You found the right door, then tried to open it in a way it simply does not open. Points for creativity, no points for results.

This usually means a request used an HTTP method the endpoint doesn't accept, like knocking with a POST when it only answers to GET. I don't see anywhere you'd be needing anything else than GET, so why don't you just stick to that and we'll both go about our days unharmed.
